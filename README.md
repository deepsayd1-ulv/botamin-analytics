# 🤖 Botamin Analytics Dashboard

Аналитический дашборд для оценки эффективности голосового бота и выявления узких мест в воронке диалогов.

## 📁 Структура проекта

```text
botamin_analytics/
├── data/
│   └── calls_week_anon.xlsx      # Исходные данные (выгрузка звонков)
├── src/
│   ├── __init__.py
│   ├── config.py                 # Константы и конфигурация колонок
│   ├── data_loader.py            # Загрузка и предобработка данных (pandas)
│   ├── funnel_analyzer.py        # Эвристический парсинг шагов воронки из текста
│   ├── metrics_calculator.py     # Расчёт конверсий и KPI
│   ├── temporal_analyzer.py      # Анализ временных паттернов
│   └── dashboard.py              # Логика построения графиков (plotly)
── streamlit_app.py              # Точка входа UI-дашборда
├── report.md                     # Полный аналитический отчёт и план А/Б-теста
├── requirements.txt              # Зависимости проекта
└── README.md                     # Инструкция по запуску

🚀 Инструкция по запуску
1. Подготовка окружения
Проект требует Python 3.10+. Рекомендуется использовать виртуальное окружение.

2. Запуск дашборда
Убедитесь, что файл с данными находится по пути data/calls_week_anon.xlsx, затем выполните:

Дашборд откроется в браузере по адресу http://localhost:8501.
📊 Краткий отчёт с выводами
Ключевые метрики (по выборке за неделю)
Всего звонков: 133
Средняя длительность: 3.8 сек
Причина завершения: 94% bot_hangup, 6% client_hangup

🔍 Главный инсайт
100% потеря конверсии на этапе установления контакта.
Средняя длительность звонка (3.8 сек) меньше времени, необходимого боту для произнесения приветствия (~12-15 сек). Бот завершает звонок (bot_hangup) из-за таймаута тишины, не получив ответа от клиента. Проблема не в скрипте оффера, а в механике первого касания и настройках таймаутов.
🧪 Гипотеза и план А/Б-теста
Гипотеза: Сокращение приветствия и увеличение таймаута ожидания ответа повысит конверсию в установление контакта (переход с шага 1 на шаг 2) с 0% до 15%.
Вариант A (Control): Текущий длинный скрипт, таймаут 4 сек.
Вариант B (Treatment):
Разбивка приветствия на 2 блока с паузой.
Увеличение таймаута ожидания ответа до 8 сек.
Добавление фразы-реаниматора: "Вы меня слышите?" при тишине.
Метрика успеха: Доля звонков, где клиент произнес хотя бы одно слово после приветствия.
Размер выборки: 500 звонков на группу (3-5 дней теста).
